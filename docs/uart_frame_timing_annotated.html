UART TX 파형 — 'A' (0x41) 전송

HIGH(1) = 아무것도 안 보내는 상태
LOW(0) = 신호 전송 중 / 시작 알림
Idle (유휴)
HIGH 유지 = 대기 중
데이터를 보내지 않을 때
항상 HIGH를 유지하는 것이 약속
Start bit
LOW로 떨어짐 = 전송 시작 신호
"지금부터 데이터 보냅니다"
수신 측이 이 하강을 감지
Data (D0~D7)
HIGH/LOW = 실제 데이터 값
LSB(bit 0)부터 전송
1비트씩 총 8비트 전송
Stop bit
HIGH 복귀 = 전송 완료 신호
"데이터 다 보냈습니다"
다시 Idle 상태로 진입
uart_tx.v FSM 상태 매핑
S_IDLE
tx = 1 (HIGH)
tx_busy = 0
전송 안 함
→
S_START
tx = 0 (LOW)
tx_busy = 1
시작 알림
→
S_DATA
tx = tx_shift[0]
tx_busy = 1
데이터 전송
→
S_STOP
tx = 1 (HIGH)
tx_busy = 1
